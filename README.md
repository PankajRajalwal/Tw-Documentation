## About This Repository

The documentation covers:

- Basic concepts and introductions.
- Important commands and syntax.
- Practical examples.
- Useful features and applications.
- Best practices and tips.

The Git documentation follows the class handout **Version Control Tools: Git and GitHub**, by Prof. Neeta Nain, MNIT Jaipur, dated 12 October 2026.

The remaining topics contain introductory general notes. Course-specific details should be checked against the respective class slides and updated where necessary.

## Purpose

The purpose of this repository is to maintain organized documentation of the concepts learned during Technical Writing Lab and provide a quick reference for revision and practical work.
